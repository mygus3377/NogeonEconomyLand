# 노건 경제 토지 구현 체크리스트

## 설계 기준
- 화폐 단위는 크레딧이다.
- 핵심 시스템은 모두 같은 지갑 상태를 공유해야 한다.
- 조작 방식의 목표는 GUI 우선이며, 명령어는 초기 세팅, 테스트, 예비 수단으로만 둔다.
- MVP 구현 순서는 데이터 코어, 명령어, GUI 골격, 상점, 토지 선택, 거래, 경매, 도박, NPC 편집 순서로 간다.

### 직업별 스킬 정의 현황

공통 구조
- 직업마다 총 8개 스킬이 정의되어 있다.
- 기본 성장 노드 5개와 고유 효과 노드 3개 구조다.
- 아래 목록은 현재 코드와 번역 리소스에 정의된 이름/설명 기준이다.

- 밭일 루틴: 최대 5레벨, 농부 경험치 레벨당 8% 증가.
- 종자 선별: 최대 5레벨, 수확 특수 효과 확률 레벨당 5% 증가.
- 손수레 훈련: 최대 4레벨, 납품가 추가로 레벨당 4% 증가.
- 흙 연구: 최대 4레벨, 수확 특수 효과 확률 추가로 레벨당 5% 증가.
- 풍작: 최대 3레벨, 완숙 작물 수확 시 추가 작물 획득 확률 증가.
- 생장 순환: 최대 3레벨, 완숙 작물 수확 시 주변 작물 성장 촉진 확률 증가.
- 밭고랑 보호: 최대 3레벨, 경작지를 밟아도 흙이 망가지지 않을 확률 증가.

어부

- 어구 정비 루틴: 최대 5레벨, 어부 경험치 레벨당 8% 증가.
- 미끼 조율: 최대 5레벨, 어획 특수 효과 확률 레벨당 5% 증가.

- 물살 파악: 최대 4레벨, 어획 특수 효과 확률 추가로 레벨당 5% 증가.
- 쌍바늘: 최대 3레벨, 낚시 성공 시 추가 어획 발동 확률 증가.
- 낚싯대 손질: 최대 3레벨, 낚시 성공 시 낚싯대 내구도 회복 확률 증가.
- 고요한 수면: 최대 3레벨, 낚시 성공 시 더 긴 행운 효과 부여.

광부
- 광물 시세 감각: 최대 5레벨, 납품가 레벨당 4% 증가.
- 갱도 루틴: 최대 5레벨, 광부 경험치 레벨당 8% 증가.
- 광맥 감지: 최대 5레벨, 채광 특수 효과 확률 레벨당 5% 증가.
- 갱차 적재: 최대 4레벨, 납품가 추가로 레벨당 4% 증가.
- 균열 파악: 최대 4레벨, 채광 특수 효과 확률 추가로 레벨당 5% 증가.
- 광맥 타격: 최대 3레벨, 광석 채광 시 추가 드롭 획득 확률 증가.
- 채굴 호흡: 최대 3레벨, 채광 중 성급함 효과로 실제 채광 속도 증가.
- 단단한 손놀림: 최대 3레벨, 채광 시 곡괭이 내구도 소모를 되돌릴 확률 증가.

- 장터 감각: 최대 5레벨, 납품가 레벨당 4% 증가.

- 양념 감각: 최대 5레벨, 요리 특수 효과 확률 레벨당 5% 증가.
- 주방 동선: 최대 4레벨, 납품가 추가로 레벨당 4% 증가.
- 맛 기억: 최대 4레벨, 요리 특수 효과 확률 추가로 레벨당 5% 증가.
- 푸짐한 한 접시: 최대 3레벨, 음식 제작/조리 시 추가 음식 1개 획득 확률 증가.
- 따뜻한 한 끼: 최대 3레벨, 음식 제작/조리 시 짧은 재생 효과.
- 손빠른 조리: 최대 3레벨, 음식 제작/조리 시 짧은 이동 속도 효과.
