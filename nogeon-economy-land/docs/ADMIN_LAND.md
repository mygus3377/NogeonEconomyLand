# 관리자 토지 (Admin Land) 시스템 가이드

관리자 토지(Spawn Land)는 서버 관리자가 지정하는 특별한 보호 구역입니다. 주로 스폰 지점이나 공공 장소를 보호하기 위해 사용됩니다.

## 1. 아이템 획득 및 설치
*   **아이템 이름**: 관리자 토지서 (Admin Land Deed)
*   **획득 방법**: 일반 상인에게서는 구매할 수 없으며, **크리에이티브 모드 인벤토리**에서 획득하거나 명령어로 지급해야 합니다.
*   **설치 제한**: 서버 전체에서 **단 하나**만 설치할 수 있습니다. 이미 설치된 경우 기존 토지를 제거해야 새로 설치할 수 있습니다.
*   **설치 방법**: 
    1. 아이템을 손에 들고 우클릭하여 '지정 모드'를 활성화합니다.
    2. 두 지점을 클릭하여 범위를 지정합니다. (일반 토지와 동일)
    3. GUI를 열어 '확정' 버튼을 누르면 설치됩니다. 설치 시 비용(크레딧)은 들지 않습니다.

## 2. 관리자 토지의 특징 및 보호 규칙
관리자 토지 내부에서는 다음과 같은 강력한 보호 규칙이 적용됩니다.

*   **메시지 표시**: 토지에 진입하면 화면 중앙에 **"이 곳은 스폰지점입니다."**라는 메시지가 표시됩니다.
*   **무적 (Invincibility)**:
    *   내부에 있는 모든 **플레이어**는 어떠한 데미지도 입지 않습니다.
    *   내부에 있는 모든 **NPC**는 어떠한 데미지도 입지 않습니다.
*   **PvP 금지**: 플레이어 간의 공격이 불가능합니다.
*   **블록 보호**:
    *   일반 유저는 블록을 부수거나 설치할 수 없습니다.
    *   **서버 관리자(OP 레벨 2 이상)**만 블록을 수정할 수 있습니다.
*   **테러 방지**: 폭발(TNT, 크리퍼 등)로 인한 블록 파괴와 엔티티 데미지가 완전히 차단됩니다.
*   **상호작용 허용**: 모든 유저는 자유롭게 출입할 수 있으며, NPC와의 상호작용(상점 이용 등)은 가능합니다.

## 3. 관리자 토지 제거 방법
관리자 토지는 실수로 제거되는 것을 방지하기 위해 일반적인 방법으로는 제거할 수 없으며, 반드시 관리자 명령어를 사용해야 합니다.

*   **제거 명령어**: `/economyadmin adminland remove`
*   이 명령어를 실행하면 현재 서버에 설치된 관리자 토지가 즉시 제거됩니다.

---
**주의**: 관리자 토지는 강력한 보호 기능을 제공하므로, 범위를 지정할 때 신중하게 설정하시기 바랍니다.
