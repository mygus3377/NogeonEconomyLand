# 강화 밸런스 최종 설계안

## 목표

- 강화 최대치를 +15에서 +20으로 확장한다.
- +1 ~ +15 구간은 지금보다 도전하기 쉽게 만들되, 비정상적으로 높은 효율은 낮춘다.
- +16 ~ +20 구간은 엔드 콘텐츠이자 크레딧/재료 소모처로 만든다.
- 완벽한 강화의 보석, 결점이 없는 강화의 보석, 강화의 보석은 매우 희귀하므로 확실한 메리트를 유지한다.
- 강화 하락 방지권 5종을 추가한다.
- 방지권을 가챠기계 보상에 넣는 작업은 여기서 구현하지 않는다.

## 강화 구간

| 구간 | 역할 |
| --- | --- |
| +1 ~ +5 | 초반 성장 |
| +6 ~ +10 | 중반 장비 안정화 |
| +11 ~ +15 | 후반 성장 |
| +16 ~ +17 | 엔드 진입 |
| +18 ~ +20 | 최종 목표 |

## 강화 하락 방지권

방지권은 하락만 막는다.

초기화, 파괴, 대실패 같은 결과가 있다면 상급/최상급 방지권도 막지 못한다.

| 아이템 | 적용 구간 | 희귀도 방향 |
| --- | --- | --- |
| 최하급 강화 하락 방지권 | +1 ~ +5 | 일반 |
| 하급 강화 하락 방지권 | +6 ~ +10 | 희귀 |
| 중급 강화 하락 방지권 | +11 ~ +15 | 희귀 |
| 상급 강화 하락 방지권 | +16 ~ +17 | 전설 |
| 최상급 강화 하락 방지권 | +18 ~ +20 | 전설, 가중치 매우 낮게 |

가챠 보상 테이블 투입은 수동으로 처리한다.

## 강화의 보석 보정

강화의 보석은 기본 보정값 자체를 너무 낮추지 않는다.

대신 강화 단계가 높아질수록 보석 효율이 감소하도록 한다.

| 보석 | 보정 |
| --- | ---: |
| 금이간 강화의 보석 | +5% |
| 갈라진 강화의 보석 | +10% |
| 결점이 있는 강화의 보석 | +15% |
| 강화의 보석 | +25% |
| 결점이 없는 강화의 보석 | +40% |
| 완벽한 강화의 보석 | 강화 성공 확정 |

완벽한 강화의 보석은 실제 획득 확률이 극히 낮으므로 확정 성공을 유지한다.

단, 완벽한 강화의 보석을 제외한 모든 보석은 목표 강화 단계에 따라 효율이 감소한다.

| 목표 강화 | 보석 효율 |
| --- | ---: |
| +1 ~ +5 | 100% |
| +6 ~ +10 | 80% |
| +11 ~ +15 | 60% |
| +16 ~ +17 | 40% |
| +18 ~ +20 | 25% |

예시:

| 상황 | 계산 |
| --- | --- |
| +12에서 결점이 있는 강화의 보석 사용 | +15% x 60% = +9% |
| +16에서 강화의 보석 사용 | +25% x 40% = +10% |
| +19에서 결점이 없는 강화의 보석 사용 | +40% x 25% = +10% |
| 완벽한 강화의 보석 사용 | 단계와 무관하게 성공 확정 |

현재 최대 기준 실제 광석 채굴 확률 추정:

| 보석 | 보석 드랍 후 내부 확률 | 광석 기준 최대 실제 확률 |
| --- | ---: | ---: |
| 완벽한 강화의 보석 | 0.1% | 0.001%, 약 광석 100,000개당 1개 |
| 결점이 없는 강화의 보석 | 0.9% | 0.009%, 약 광석 11,111개당 1개 |
| 강화의 보석 | 4.0% | 0.04%, 약 광석 2,500개당 1개 |

## 장비별 강화 효과 효율 방향

여기서 말하는 효율은 강화 성공 확률이 아니라 강화 단계로 얻는 실제 스탯 증가량을 뜻한다.

기존 +11 ~ +15 구간에서 강화 단계로 얻는 실제 스탯 증가량이 과도하므로, +20 확장 전에 장비별 강화 스탯 보정치를 낮춘다.

| 장비군 | 방향 |
| --- | --- |
| 무기 | 기존 강화 효율의 약 60 ~ 70% 수준으로 감소. +16 이후 증가량은 작게 유지 |
| 총 | 무기와 동일. 큰 곱연산 피해 증가를 피함 |
| 활 | 무기와 동일. 화살 속도와 투사체 관련 보정은 상한 유지 |
| 도구 | 전투 밸런스 영향이 작으므로 덜 너프. 단 +16 이후 효율은 완만하게 |
| 방어구 | 가장 강하게 너프. 현재도 방어 체급이 과도함 |

## 방어구 별도 너프

방어구는 강화 최대치만 늘리면 안 된다.

기본 체급 자체를 낮춰야 한다.

권장 방향:

| 방어구 보너스 | 새 강도 |
| --- | ---: |
| 방어력 | 기존의 약 45% |
| 방어 강도 | 기존의 약 50% |
| 최대 체력 | 기존의 약 60% |

방어구 강화로 실질적인 0데미지 상태가 나오면 안 된다.

최소 데미지와 방어력 관통 로직은 계속 작동해야 한다.

## 구현 체크리스트

- 강화 최대치를 +20으로 확장한다.
- 강화 성공 확률 테이블을 교체한다.
- 강화 비용 테이블을 교체한다.
- 강화 보석 기본 보정은 유지하되, 목표 강화 단계에 따른 효율 감쇠를 추가한다.
- 완벽한 강화의 보석은 성공 확정으로 유지한다.
- 강화 하락 방지권 5종을 추가한다.
- 목표 강화 단계에 따라 방지권 적용 구간을 나눈다.
- 하락 방지와 초기화 방지를 분리한다.
- 무기, 총, 활, 도구, 방어구 강화 효율을 재조정한다.
- 대장간 UI의 강화 확률, 비용, 보석 보정, 방지권 설명을 갱신한다.
- 강화의 보석 선택 GUI에 도움말 버튼을 추가한다.
- 도움말에는 보석 기본 보정, 강화 단계별 효율 감소, 완벽한 보석의 확정 성공을 설명한다.
- 각 강화의 보석 툴팁에도 기본 보정과 고강화 구간 효율 감소 안내를 추가한다.
- 새 방지권을 가챠 보상 테이블에는 넣지 않는다.
